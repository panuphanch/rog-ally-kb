# ROG Ally Knowledge Base

Personal knowledge base for my ASUS ROG Ally (original, Z1 Extreme), currently running [Bazzite](https://bazzite.gg).

## Goals

1. Play **EA Sports FC 26** (mostly offline modes, bought on Steam).
2. Play on the **TV**: wired HDMI via dock (must-have), wireless (nice-to-have) — TVs: LG webOS, Xiaomi Google TV, old Chromecast.
3. Use a **Nintendo Switch Pro Controller**.
4. Better **battery life** in handheld mode (soft goal).

Constraint: **one OS only** on the Ally (Bazzite *or* Windows, no dual-boot).

## Layout

- `docs/research/` — research findings (one page per topic)
- `docs/runbook.md` — the final, verified setup runbook (written when the planning map is done)

Planning happens on GitHub Issues: see the issue labelled `wayfinder:map`.
